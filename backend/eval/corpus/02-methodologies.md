# What a methodology defines

A methodology is the rulebook a project follows to turn its activity into a number of credits. It defines which activities qualify, how to draw the project boundary, which greenhouse gases count, and which equations convert measured data into tonnes. A cookstove methodology and a forestry methodology share almost nothing beyond the overall structure.

The baseline scenario is the heart of every methodology: it describes what would have happened without the project. Emission reductions are the difference between baseline emissions and project emissions, minus leakage. A baseline that is set too high creates credits for reductions that never happened, which is why baselines get the most scrutiny during validation.

Methodologies also set the monitoring plan. They list each parameter the project must measure, how often, with what equipment, and how to handle missing data. For example, the fictional methodology MD-AM-0042 for biogas digesters requires the gas flow meter to be calibrated every twelve months, and tells the project to use the lowest reading of the period when a month of data is lost.

Standards revise methodologies when the science or the market changes. A revision usually applies to new projects at once, while running projects may keep the old version until their crediting period renews. That grace rule keeps the rules stable for investors, at the cost of letting outdated assumptions live on for years.

The project boundary decides which emission sources are counted. Draw it too narrowly and the project ignores emissions it causes; draw it too widely and monitoring becomes impossible. A methodology lists the sources that must be inside the boundary and the ones that may be left out because they are small.

Conservative choices are a rule that runs through every methodology. When a parameter is uncertain, the project must pick the value that gives fewer credits, for example the lower end of a confidence interval, so that errors shrink the claim instead of inflating it.
