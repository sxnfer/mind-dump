# Measurement, reporting, verification and leakage

MRV stands for measurement, reporting and verification, the cycle every project repeats for each monitoring period. The project measures its parameters as the monitoring plan requires, writes them into a monitoring report, and an independent verification body checks the report before any credits are issued.

Verifiers are accredited auditors. They visit the site or inspect it remotely, sample the raw data, recompute the totals and compare them with the report. A material misstatement, often defined as an error larger than five percent of the claimed reductions, means the report must be corrected before the verifier signs.

Leakage is the emission increase that a project causes outside its boundary. When a forest is protected, the demand for timber does not vanish, so logging can shift to a neighbouring forest. Methodologies estimate this with a leakage deduction, a percentage subtracted from the claimed reductions, which for avoided deforestation often lies between ten and forty percent.

Remote sensing has changed verification for land projects. Satellite images taken every few days let anyone check forest cover against the project's claims, and some registries now ask projects to publish the boundary of the protected area as a map file so that outsiders can run that check themselves.

Uncertainty also enters through sampling. A forest inventory measures trees on a set of sample plots and scales the result up to the whole area, so a methodology may require a minimum number of plots and deduct credits when the confidence interval is wide.

Digital MRV is the name for collecting monitoring data directly from meters and sensors instead of spreadsheets typed by hand. It shortens the time between measurement and issuance, but the verifier must then check the data pipeline itself, not only the numbers it produces.
